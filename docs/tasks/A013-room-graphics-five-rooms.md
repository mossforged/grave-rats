# A013 - Company graphics for five new room types (art)

**Read:**
- `AGENTS.md`;
- `docs/design/tone-bible.md`;
- `docs/tasks/A010-company-graphics-and-decals.md` and `docs/screens/A010/sheet.png` (the two voices and the style John approved);

**Needs:** nothing.
**Autonomy:** human-gated (John approves the copy and look).

The lead modelled prop sets for engineering, a bio lab, the bridge, crew quarters and the mess. These rooms will appear in a second derelict layout (A014, then a code task). A010 made the medbay feel like a real, cheap, uncaring company's ship: "CO-PAY REQUIRED BEFORE RESUSCITATION". Do the same for these five rooms, with the same two voices:
- **the dead ship's original owner:** faded, earnest, now ironic;
- **Remnant Asset Recovery:** fresh stickers and tape over the top.

The satire is deadpan and specific, never quipping.

## Do
Flat, front-on graphics on a plain background, cut-out ready. Save each to `assets/source/A013-room-graphics/A013-NN.png` with a `.prompt.md`. Text must be legible and spelled right; note any garbling.

1. **Engineering (A013-01):**
   - a reactor safety board ("DAYS SINCE LAST CONTAINMENT EVENT");
   - a lockout/tagout notice;
   - a "RADIATION BADGE MUST BE WORN (BADGES SOLD SEPARATELY)" style sign;
   - stencilled hazard plates for the reactor cage and power cells.
2. **Bio lab (A013-02):**
   - specimen-tank labels (numbered, some redacted);
   - a biohazard containment notice;
   - an ethics-board approval certificate, expired;
   - a fume-hood warning.
3. **Bridge (A013-03):**
   - a captain's commendation plaque;
   - a "THE CAPTAIN'S CHAIR IS A PRIVILEGE, NOT A RIGHT" poster;
   - deck and section numbering;
   - nav chart decals for the nav table (abstract, readable from above).
4. **Crew quarters (A013-04):**
   - personal touches that turn the horror human: a child's drawing, a "WORLD'S OKAYEST DAD" mug decal, a bunk name tag, a rent notice for the bunk ("BUNK RENTAL DEDUCTED FROM WAGES");
   - a "QUIET HOURS ARE BILLABLE" sign.
5. **Mess (A013-05):**
   - a food dispenser menu with prices (everything costs, including water);
   - a "NUTRITION PASTE: NOW WITH 12% MORE FLAVOUR" poster;
   - a passive-aggressive fridge-etiquette note;
   - a birthday banner still hanging.
6. **Remnant overlays for these rooms (A013-06):** "ASSESSED" and "SALVAGE PRIORITY: LOW / MEDIUM / HIGH" stickers; a "BIOLOGICAL MATERIAL NOT COVERED BY CONTRACT" tape; inventory tags for the reactor core and the captain's chair.
7. **Contact sheet** at `docs/screens/A013/sheet.png`, labelled.
